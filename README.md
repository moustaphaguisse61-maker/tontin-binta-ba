# Tontin Binta Ba

Prototype frontend de gestion de tontine pour Binta Ba.

## Publication GitHub Pages

Le workflow `.github/workflows/pages.yml` publie automatiquement le site sur GitHub Pages apres chaque push sur `main`.

> Ce prototype ne contient pas encore d'authentification, de base de donnees ou de traitement securise de pieces d'identite. Ne pas utiliser de donnees reelles avant l'ajout du backend et la validation juridique.
